# SOP orkestrasi kampanye Event

**Tujuan.** Event adalah orkestrator offline dan online.

**Langkah.**

1. Baca KB MRP.
2. Tulis `campaign_calendar.md`: event nasional, aktivasi sponsorship, dan slot digital.
3. Picu MBLP untuk jalur kreatif dan Digital untuk homeless media serta jadwal.
4. Jangan menulis konten final dan jangan mengedit KB atau command center.
5. Kirim laporan status ke MRP setelah calendar disetujui Endo Eko Satryo.
