# SOP kebersihan knowledge base

**Langkah.**

1. Tiap file punya frontmatter `dept`, `status`, `owner`, `date`, `tags`.
2. Tiap klaim menyebut path sumber. Wikilink tidak wajib.
3. Hanya CoS MRP yang menulis KB bersama dan command center. Sub-fungsi lain menulis draf di foldernya dan status-reports.
4. Jika git bentrok, jangan menimpa file sub-fungsi lain. Buat file baru dengan sufiks nama sub-fungsi.
5. Indeks `00_index.md` diperbarui MRP bila ada fakta penting.

**Selesai bila.** Dari laporan mingguan, jejak ke brief, status-report, dan keputusan bisa dibuka di Cursor.
