# SOP sinkron KB dan laporan ke command center

**Tujuan.** Event, MBLP, dan Digital selalu sejajar dengan fakta KB, dan kemajuan mereka terlihat di command center tanpa mengedit papan itu sendiri.

**Langkah.**

1. Baca `knowledge-base/` dan `knowledge-base/command-center.md`.
2. Jika rencana kerja bertentangan dengan fakta `approved`, berhenti dan tanya MRP.
3. Kerjakan draf hanya di `knowledge-base/<dept>/drafts/`.
4. Tulis laporan status di `knowledge-base/status-reports/YYYY-MM-DD_<dept>_<topik>.md` berisi: pekerjaan, status, path draf, approval yang diminta.
5. CoS MRP memasukkan baris itu ke command center.
6. Baca ulang command center sebelum langkah berikutnya.

**Selesai bila.** Ada laporan status dengan path, dan command center sudah mencerminkan status terbaru setelah MRP memperbarui.
