# SOP jalur kreatif MBLP

**Urutan wajib**, satu file per tahap:

1. `01_content_planning.md` dari campaign calendar Event dan fakta KB.
2. `02_content_draft.md`.
3. `03_content_creative.md` (arahan key visual atau naskah, bukan file produksi jadi).
4. Revisi setelah catatan Kania Hapsari.
5. Final approval. Materi lintas fungsi juga perlu Heppy Wulansari.
6. Hanya item final masuk `content_bank.md`.

Setiap tahap selesai diikuti laporan status ke MRP. Digital tidak boleh menjadwalkan item di luar content bank.
