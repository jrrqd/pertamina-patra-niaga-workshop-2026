# Laporan status ke command center

Event, MBLP, dan Digital menulis di sini. MRP membaca dan memasukkan ke `knowledge-base/command-center.md`.

Nama file: `YYYY-MM-DD_<dept>_<topik>.md`

```yaml
---
dept: evm | mblp | dgm
status: draft
owner: <chief of staff>
date: 2026-11-27
tags: [status-report]
---
```

Isi wajib: pekerjaan, status (`draft` / `pending_approval` / `blocked`), path draf, approval yang diminta, satu kalimat dampak ke calendar atau content bank.
