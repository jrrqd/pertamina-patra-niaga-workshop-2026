# Command center kampanye

Semua sub-fungsi boleh membaca file ini kapan saja. Hanya CoS MRP yang mengedit. Sub-fungsi lain mengirim laporan status ke `knowledge-base/status-reports/`.

Kampanye latihan: lihat `knowledge-base/company/campaign_brief.md`.

## Cara baca status

- `belum mulai` — belum ada laporan
- `draft` — ada draf, belum diajukan
- `pending_approval` — menunggu manusia
- `approved` — keputusan manusia sudah tercatat di `knowledge-base/decisions/`
- `blocked` — bertentangan dengan fakta KB atau menunggu sub-fungsi lain

## Pembaruan terakhir

Belum ada laporan status dari Event, MBLP, atau Digital. CoS MRP mengisi baris di atas setelah menerima file di `knowledge-base/status-reports/`.
