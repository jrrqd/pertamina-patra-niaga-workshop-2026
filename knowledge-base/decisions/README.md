# Keputusan manusia

Approver menulis satu file per keputusan. Agen tidak membuat file ini.

Nama: `YYYY-MM-DD_<dept>_<topik>.md`

```yaml
---
dept: <dept>
status: approved
owner: <nama manusia>
date: 2026-11-27
tags: [decision, approved]
---
```

Isi: objek (wikilink), putusan (setuju atau tolak), alasan satu kalimat.
